# War Room Command Console

Personal-use browser companion prototype for the War Room board game.

## How to use

1. Open `index.html` in a modern browser.
2. Enter game, round, nation, and player details.
3. Upload your own photo/scan of your physical War Room map.
4. Write movement and production orders.
5. Lock orders when ready.
6. Use Print / PDF to create a reveal sheet.

## Features

- Movement order writing
- Production / placement order writing
- Duplicate command warning
- Missing field warnings
- Lock/unlock orders
- Local browser save/load
- JSON export/import
- Uploaded map reference
- Map note pins
- Printable reveal sheet

## Personal use note

This prototype does not include Nightingale Games artwork, logos, official map files, charts, or rulebook text. It is designed for personal use with your own physical copy and your own uploaded board image.
